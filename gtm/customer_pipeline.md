# Customer Pipeline

Pipeline stage definitions and current status. This is a status snapshot, not a live-updating tracker — update the "Current status" section as work happens and date each change.

## Stages

1. **Sourced** — company identified and fit-tiered (see [customer_qualification.md](customer_qualification.md)), not yet contacted.
2. **Outreach sent** — personalized research-only request sent (see [validation_plan.md](validation_plan.md)).
3. **Interview scheduled**
4. **Interview completed** — logged in [interview_scorecard.csv](interview_scorecard.csv).
5. **Segment validated / disconfirmed** — per the rule in [validation_metrics.md](validation_metrics.md).
6. **Pilot conversation** — only reached after segment validation; see [paid_pilot.md](paid_pilot.md).
7. **Pilot started**

Nothing below stage 6 should involve pricing or a product pitch.
